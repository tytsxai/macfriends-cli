# 中文用户指南

## 推荐入口

如果你不想记命令，优先使用本地控制台：

```bash
macfriends 控制台 --open
```

默认会打开：

```text
http://127.0.0.1:8765
```

页面里可以直接点按钮完成：
- 查看当前状态
- 准备受控微信副本
- 启动并登录
- 连接检测
- 全量扫描联系人
- 导出 CSV / JSON
- 查看 CLI 日志与 agent 日志
- 断开 agent 或清理运行状态

控制台只监听本机地址，不需要云端账号，不上传微信数据。

## 命令行快速路径

如果你更习惯命令行，可以使用中文别名：

```bash
macfriends 状态
macfriends 准备
macfriends 启动 --login
macfriends 连接
macfriends 扫描 --all
macfriends 导出 --format csv
```

对应英文命令仍然可用：

```bash
macfriends status
macfriends prepare
macfriends launch --login
macfriends attach
macfriends scan --all
macfriends export --format csv
```

## 状态怎么看

先运行：

```bash
macfriends 状态
```

重点看这几项：
- `当前阶段`：现在处于准备前、已准备、已启动但阻塞、真实运行态已就绪等哪个阶段
- `支持的微信版本`：当前 adapter 锁定支持的微信版本
- `已安装微信版本`：本机 `/Applications/WeChat.app` 的版本
- `受控微信版本`：MacFriends runtime 里受控副本的版本
- `目标版本支持`：当前受控微信是否符合版本和架构要求
- `真实运行态 Ready`：agent 和核心原语是否达到真实可用条件
- `Fixture 测试模式`：如果是“是”，说明当前只是测试链路，不能当正式结果
- `Release Blocker` / `阻塞项`：现在不能继续的具体原因
- `下一步`：按这里给出的动作继续处理
- `兼容提示`：微信更新、版本不匹配、默认路径找不到微信时会在这里说明

常见阶段含义：

| 阶段 | 含义 | 下一步 |
| --- | --- | --- |
| `尚未准备` | 还没有受控微信副本 | 运行 `macfriends 准备` |
| `已准备，等待启动` | 受控副本已存在 | 运行 `macfriends 启动 --login` |
| `已启动但未满足生产条件` | agent 可连接，但还不能视为生产可用 | 看阻塞项和 agent 日志 |
| `进程存在但 agent 未连接` | 微信进程还在，但 socket 不可用 | 退出受控微信后运行 `macfriends 清理` |
| `已准备但目标不匹配` | 微信版本或架构不符合要求 | 确认 4.1.8 arm64 后运行 `macfriends 准备 --force` |
| `真实运行态已就绪` | 满足真实 Ready 条件 | 可以生成正式链路扫描并导出 |

## 中文命令别名

| 中文命令 | 英文命令 | 作用 |
| --- | --- | --- |
| `检查` | `doctor` | 检查环境、版本、工具、Ready 门禁 |
| `状态` | `status` | 查看产品级总状态和下一步 |
| `准备` | `prepare` | 创建或刷新受控微信副本 |
| `启动` | `launch` | 启动受控微信 |
| `连接` | `attach` | 连接 agent 并查看运行态 |
| `资料` | `profile` | 读取当前登录资料 |
| `联系人` | `contacts` | 读取联系人列表 |
| `扫描` | `scan` | 扫描联系人关系 |
| `导出` | `export` | 导出最近一次正式链路扫描 |
| `断开` | `detach` | 请求 agent 停止 |
| `清理` | `cleanup` | 清理 pid、socket、run-state |
| `控制台` | `serve` | 启动本地 Web 控制台 |

参数仍使用英文，例如：

```bash
macfriends 准备 --force
macfriends 扫描 --all
macfriends 导出 --format csv
macfriends 控制台 --addr 127.0.0.1:8787 --open
```

## 真实生产边界

当前工具不会伪造扫描结果。只有同时满足以下条件，才算真实可用：
- `runtime_ready=true`
- `fixture_enabled=false`
- `release_blockers=[]`
- `primitive_resolution.profile/contacts/scan = resolved`

如果看到 `profile_primitive_unresolved`、`contacts_primitive_unresolved`、`scan_primitive_unresolved`，说明真实原语还没闭环。页面和命令都会显示失败，这是正确行为；当前 beta 包也必须通过 `MACFRIENDS_ALLOW_BETA_RELEASE=1` 显式生成。

## 微信更新怎么办

微信桌面版可能随时升级。MacFriends 不会假设“最新版本一定兼容”，而是每次运行时检测：
- 本机安装的微信版本
- 受控副本版本
- 当前 adapter 锁定版本
- agent 真实运行态

如果微信升级后版本不匹配，`状态` 和 Web 控制台会显示兼容提示。此时不要强行扫描，也不要把 fixture 结果当正式结果；需要等待或开发新的 adapter。
