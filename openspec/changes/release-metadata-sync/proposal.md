# Release Metadata Sync

## Why

The repository release version is derived from Cargo package metadata, and package/install documentation must keep matching the archive names generated by `scripts/package.sh`. After the 0.1.2 release metadata landed upstream, local release-facing documentation needs to preserve that version while adding beta opt-in packaging language.

## What Changes

- Keep the Rust package metadata and lockfile package entry at the current upstream `0.1.2`.
- Update documented release artifact names to `macfriends-0.1.2-macos-arm64`.
- Keep new release guard and beta-only caveats in Unreleased changelog notes instead of rewriting the already tagged 0.1.2 history.
- Add an OpenSpec change record for the release metadata sync.

## Scope

This change does not alter native agent behavior, compatibility targets, or installation paths. It synchronizes release metadata and release-facing documentation with the current upstream version while preserving beta readiness boundaries.
